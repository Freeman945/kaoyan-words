# 考研词记

一个给自己用的考研英语背单词网站。

按**艾宾浩斯遗忘曲线**安排复习，学习进度存在云端（换电脑、换手机、退出登录都不会丢），
可以装到手机主屏幕上当 App 用，每周末还会把学习情况发到邮箱。

### 在线使用 → **[kaoyan-words.vercel.app](https://kaoyan-words.vercel.app)**

> ⚠️ 国内直连需要代理 —— `*.vercel.app` 这个域名后缀被 DNS 污染了。
> 服务器本身是通的（实测 Vercel 的 IP 延迟 100ms 左右），只是域名被针对。
> 解决办法是绑一个自己的域名，见[完整手册](docs/05-完整手册.md)。
>
> 这是一个**个人项目**，为 2028 考研准备，没有开放注册给陌生人。

## 它长什么样

背单词页只有三样东西：进度、一个单词、三个按钮。

```
← 上一个 ──────────────────────  38 / 117

              consequence
              [ˈkɒnsɪkwəns]

              显示释义  空格

     不认识         模糊          认识
    1 分钟后      15 分钟后       1 天后
       1             2             3
```

按钮下面那行不是写死的，是**真实的复习算法当场算出来的** ——
点之前就知道「点下去下次什么时候再见」。

## 比较特别的地方

| | |
| --- | --- |
| **完整的艾宾浩斯阶梯** | 答对一次间隔往上走一档：`1 分钟 → 5 分钟 → 15 分钟 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天 → 60 天 → 120 天`。前三档都在一次学习之内，靠「本轮内重新排队」真正落地（不做这一步，前三档就是摆设） |
| **星级熟练度** | 0~5 颗，新词 3 颗起步。认识 +1、不认识 −1、模糊不动 |
| **满星静默** | 连续两次满星就暂时不考它了。14 天冷却，之后自动回来 —— 否则就是单向门，词会彻底消失然后忘光 |
| **重点词** | 不看「什么时候到期」，只看**错误记录**：答错多的、一直模糊的、拖很久没复习的。而且会告诉你**为什么**挑中它 |
| **不设每日配额** | 系统不规定你每天背多少，可学的词一次性都给你，背到不想背就停。它只根据最近两周的实际节奏算「照这样什么时候能背完」 |
| **退出能接着来** | 退出去是 book，回来还是 book |
| **看上一个** | 按 `←` 可以往回翻看刚才的词（只读，不会把同一个词答第二遍） |
| **每周末邮件周报** | 学了几天、新学多少、最该盯的词、预计哪天背完、考试前来不来得及 |
| **晚上 10 点提醒** | 那天一次都没学就发封邮件（只要开始背了就不打扰） |
| **能装到手机上** | 有安卓 APK，全屏打开、没有地址栏 |

## 手机上怎么用

**安卓**：手机浏览器打开
**[kaoyan-words.vercel.app/kaoyan-words.apk](https://kaoyan-words.vercel.app/kaoyan-words.apk)**
直接下载安装（需要允许「未知来源」）。

它是一个 TWA —— 本质是个壳，打开后加载线上网站，
所以**代码更新后手机上自动就是新版**，不用重新下载。

**iPhone**：用 Safari 打开网址 → 分享 → 添加到主屏幕。

## 技术栈

| 用途 | 技术 |
| --- | --- |
| 前端 | Next.js 16（App Router）+ React 19 + TypeScript |
| 样式 | Tailwind CSS 4 |
| 数据库 | Supabase（PostgreSQL + Auth + RLS 行级安全） |
| 部署 | Vercel（含定时任务） |
| 邮件 | Resend |
| 测试 | Node 内置测试运行器 + PGlite（WASM 版真 PostgreSQL） |

刻意**没有**用 Redis、Docker、微服务 —— 这个用量不需要。

## 项目结构

```
app/          页面和 Server Action（Next.js App Router）
components/   界面组件（只管显示，不含数据请求）
lib/          核心逻辑：算法（纯函数、可测）+ 数据访问
types/        类型定义（含手写的数据库表结构，列名写错会编译不过）
supabase/     建表 / RLS 策略 / 种子数据 / 测试替身
scripts/      一次性工具：启动器、词库转换、图标生成、SQL 校验
docs/         讲解文档
public/       图标 / APK / assetlinks
```

约 **6600 行源码** + **250 个自动化测试**（算法、统计、组件渲染、数据库安全策略）。

## 本地运行

```bash
npm install
npm run dev        # 打开 http://localhost:3000
```

需要先在 `.env.local` 里填两个 Supabase 变量，
并在 Supabase 的 SQL Editor 里执行 `supabase/schema.sql` 和 `supabase/seed.sql`。

> 完整的配置步骤、环境变量清单、部署流程都在 **[完整手册](docs/05-完整手册.md)** 里。

## 数据来源与许可

**词库**来自开源项目
[LinXueyuanStdio/DictionaryData](https://github.com/LinXueyuanStdio/DictionaryData)，
选用其中《2017 考研大纲词汇（黄皮书）》5581 词，去掉查不到释义的，实际 **5490 词**。

> 该项目采用 **Apache License 2.0**，使用时需保留版权声明 —— 这一节就是。
>
> ⚠️ 这份数据只有「单词 + 音标 + 释义」，**没有例句**，所以单词卡上的例句位置是空的。

**图标**由 `scripts/make-icons.py` 生成（深灰底 + 白色「词」）。
